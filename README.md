# フィールドノート

山菜・果実と樹の実・きのこ・登山・温泉の記録と図鑑をまとめた、ノート形式のアプリです。
仲間うちで使うための、ログイン制のグループ向けアプリです。

**アプリのURL** https://tsurughi2999-alt.github.io/field-note/

## できること
- 山菜採り：図鑑、旬の暦、スポット、収穫記録、収穫マップ、持ち物、レシピ、ブログ、パトロール、メモ
- 果実と樹の実・きのこ：図鑑、スポット、収穫記録
- 登山（百名山）、温泉の記録
- 情報：現在地、天気、日の入り、潮、クマ対策
- みんな：お知らせ、名簿、リンク、使い方・Q＆A
- 参考資料：天気・地図・登山・安全などのリンク集（自分で追加・削除できます）
- 地域マップ：県ごとのスポット数（管理者のみ表示）
- グループのカレンダー（Googleカレンダー）の表示
- 自分で追加したページ：予定（カレンダー）、記録、スポット、メモ、リンク
- 表紙のデザインと色、ページの紙の色を選べます

## 使い方
1. 上のURLを **Chrome**（iPhoneはSafari）で開きます。
2. 管理者から聞いたIDとパスワードでログインします。初回は通信が必要です。
3. Chromeの︙メニューから「アプリをインストール」を選ぶと、ホーム画面にアイコンが置かれます。

記録は端末ごとに、その端末のブラウザの中に保存されます。
ブラウザのデータを消すと記録も消えるため、大事な記録は「データのバックアップ」で書き出してください。

## ファイル構成
| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（1ファイル） |
| `manifest.json` | ホーム画面に追加するための設定 |
| `sw.js` | オフライン対応（ネットワーク優先で、更新はすぐ反映されます） |
| `icon-180.png` `icon-192.png` `icon-512.png` | アプリのアイコン |
| `shared.json` | みんなに配信するデータ（暗号化されています） |

## 管理者向けメモ
- 更新するときは、変更したファイルをGitHubにアップロードします（同名のファイルは上書き）。
- 配信データは、アプリの管理者モードで書き出した文字を `shared.json` に貼り付けて更新します。
- パスワードやIDをこのリポジトリに書かないでください。

## 注意
- 毒草・毒きのこに似たものがあります。少しでも迷ったら採らず、食べないでください。
- 山菜・きのこ採りは、入山の許可や採取のルールを守って行ってください。
- 位置情報は端末の中だけで使い、共有するときは広いエリアにぼかしています。
